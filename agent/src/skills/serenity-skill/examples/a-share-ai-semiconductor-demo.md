> Note: This is a dated example. Always use live sources for current research.

## Prompt

```
用 serenity-skill 深度调研现在 A 股 AI 半导体产业链。
请联网查公告、财报、问询函、互动易、招投标、环评/能评、专利、客户认证和财务质量，
先排产业链层级，再找 5 个最值得优先研究的标的。
```

## Reasoning

先看带宽和工艺约束，再看纯算力芯片。AI 需求继续扩张时，先紧起来的往往是内存互连、CMP/减薄、刻蚀和耗材这些决定供给能不能爬坡的环节。

## Layer ranking (before companies)

先排产业链层级，再排公司。我会优先看这几层：内存互连芯片、CMP/减薄、关键刻蚀设备、CMP/电镀耗材、先进封装/测试。

纯 AI 算力芯片和光模块虽然业绩弹性强，但估值和拥挤度更高，更适合作为情绪温度计而非优先深研对象。
